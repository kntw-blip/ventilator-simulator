# 人工呼吸器シミュレータ

人工呼吸器の設定・患者の病態・バイタルサインが連動して動く、教育用のWebシミュレータです。
看護師・研修医から呼吸療法士・臨床工学技士まで、表示レベルを切り替えて使えます。

> 教育用のシミュレーションです。生理学モデルは学習のために単純化されており、実際の患者の診療判断には使用しないでください。

## できること

- **換気モード**: VC-A/C、PC-A/C、PRVC、SIMV（VC/PC）＋PS、PSV/CPAP、APRV、Tピース、NPPV（S/T・CPAP）、HFNC、通常の酸素療法（鼻カニュラ・簡易マスク・リザーバー）
- **病態**: 正常肺、ARDS、COPD急性増悪、気管支喘息、重症肺炎（敗血症）、高度肥満、神経筋疾患、術後（上腹部手術）。重症度・性別・身長・体重・循環血液量を設定でき、理想体重から換気量を評価します
- **連動する表示**: 気道内圧・流量・換気量（詳細モードでは食道内圧）の波形、P-V／F-Vループ、計測値。生体情報モニタ（心電図・SpO2・動脈圧・カプノグラム）と CVP・PPV
- **非同調の再現**: ミストリガー、ダブルトリガー、オートトリガー、サイクルの遅れ・早すぎるサイクル、フロー不足が、患者の吸気努力と呼吸器の設定から自然に発生し、検出・集計されます
- **アラーム**: 気道内圧上限・回路外れ・分時換気量・1回換気量・呼吸回数・無呼吸・SpO2・心拍数・血圧・EtCO2。設定変更とアラーム音、消音
- **急変イベント**: 緊張性気胸、痰による閉塞、チューブ閉塞、気管支攣縮、片肺挿管、カフリーク、回路外れ、計画外抜管、不穏、出血。対応する処置（吸引・ドレナージ・輸液・昇圧薬・リクルートメント・腹臥位など）
- **トレンド・血液ガス**: SpO2・HR・MAP・EtCO2・PaCO2・換気量などの時間経過、動脈血ガス（pH・PaCO2・PaO2・HCO3-・BE・乳酸・P/F・A-aDO2）
- **ウィーニング・抜管**: 時間経過による病態改善（肺傷害を起こす設定では遅れる）、SAT、SBT（PS 5/PEEP 5・CPAP・Tピース）と中止基準、RSBI、カフリークテスト、咳嗽評価、抜管後の酸素療法の選択、喉頭浮腫、再挿管
- **学習シナリオ**: ARDSの肺保護換気、COPDのauto-PEEP、術後のウィーニングと抜管、急変対応（DOPE）、神経筋疾患の抜管後NPPV、COPDへのNPPV導入。ステップごとの課題・ヒント・解説と、安全性指標による振り返り
- **初級／詳細の切替**: 初級では各設定の意味と「いま起きていること」の解説を表示。詳細では駆動圧・コンプライアンス・気道抵抗・auto-PEEP・時定数・P0.1・非同調指数・RSBI・患者の内部状態を表示

## 生理学モデルの概要

| 要素 | モデル |
| --- | --- |
| 呼吸メカニクス | 単一コンパートメント（Paw − Palv = R·V̇、Palv = Pel(V) − Pmus）。過膨張域の非線形コンプライアンス、開放圧・閉塞圧のヒステリシスによるリクルートメント、COPDの呼気流量制限（臨界閉塞圧） |
| 自発呼吸 | 神経性吸気努力（Pmus）を PaCO2・PaO2・代謝性アシドーシス・鎮静（RASS）・痛みから生成。負荷補償、呼吸筋疲労（圧時間指数）、Hering–Breuer 反射による同調、人工呼吸器関連横隔膜機能障害 |
| 人工呼吸器 | フロー／圧トリガー、時間・流量（ETS）サイクル、立ち上がり時間、SIMV同期、PRVCの圧調整、PSVのバックアップ換気、NPPVのリーク推定と補償 |
| ガス交換 | 解剖学的・肺胞死腔、CO2 貯蔵、FRCへの酸素洗い込み、正常・低V/Q・シャントの3コンパートメント、静脈血の酸素貯蔵、Severinghaus の解離曲線（pH・体温補正）、Henderson–Hasselbalch |
| 循環 | 平均体循環充満圧と右房圧の差による静脈還流、胸腔内圧の伝達（胸壁エラスタンス比）、圧受容体反射、低酸素・アシドーシスによる心機能低下、拍動ごとの1回拍出量の呼吸性変動（PPV） |

単位は圧 cmH2O、血圧 mmHg、流量 L/分、換気量 mL です。

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm run build      # 本番ビルド（dist/）
npm run validate   # 病態ごとの典型設定での生理学的な値を表示
npm run check-scenarios  # 学習シナリオが想定の操作で完了できるか確認
```

構成:

- `src/engine/` 生理学エンジン（UIに依存しない TypeScript）
  - `simulator.ts` メカニクス・換気器・ガス交換・循環・アラーム・ウィーニング
  - `patients.ts` 病態プリセットと重症度・体格補正
  - `physiology.ts` 酸素解離曲線・酸塩基
  - `defaults.ts` 初期設定・モードの説明
- `src/ui/` 画面（波形・設定ノブ・モニタ・各タブ）と解説ルール（`explain.ts`）
- `src/scenarios/` 学習シナリオ
